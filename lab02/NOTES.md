# NOTES

## Рабочая папка, индекс, коммит

Рабочая папка — это текущее состояние файлов проекта, с которыми я работаю на диске.

Индекс — промежуточная область, куда я добавляю изменения командой git add перед коммитом.

Коммит — зафиксированное состояние проекта в истории Git. У коммита есть автор, дата, сообщение и ссылка на предыдущий коммит.

## Git и GitHub

Git — распределённая система контроля версий. Она работает локально и хранит историю изменений.

GitHub — платформа для размещения Git-репозиториев в интернете, совместной работы, code review и публикации проектов.

Git — это инструмент, GitHub — это сервис для работы с Git-репозиториями.

## Использованные команды

git status — показывает текущее состояние репозитория: какие файлы изменены, какие добавлены в индекс, какие не отслеживаются.

git diff — показывает разницу между рабочей папкой и индексом, то есть ещё не добавленные изменения.

git diff --staged — показывает разницу между индексом и последним коммитом, то есть изменения, подготовленные к коммиту.
