# Лабораторная 03 — Git-воркшоп

## Часть 2. Сравнение версий и поиск изменений

### Выполненные команды

- git log --oneline --stat — краткая история коммитов с указанием изменённых файлов и числа строк.
- git diff HEAD~2 HEAD -- lab03/calc.py — разница между двумя коммитами: что добавилось в файл между версиями.
- git show HEAD~1 — содержимое одного коммита: автор, дата, сообщение и изменения.
- git log -S"def" --oneline -- lab03/calc.py — поиск коммитов, где появлялось или исчезало слово "def". У меня функций нет, поэтому вывод пустой.
- git blame lab03/calc.py — кто и в каком коммите добавил каждую строку файла.

### Чем отличаются git diff, git show и git log

- git diff — сравнивает два состояния (рабочую папку, индекс или коммиты) и показывает разницу.
- git show — показывает один коммит: метаданные и его изменения.
- git log — показывает историю коммитов.

### Что нашли log -S и blame

- git log -S"def" — ничего не нашёл, потому что в calc.py нет функций.
- git blame — показал, что первая часть файла добавлена коммитом "Add addition", строки вычитания — "Add subtraction", умножения — "Add multiplication".
